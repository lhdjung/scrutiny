# Data with duplications

A fictional dataset with observations of flying pigs. It contains
multiple duplicates. For demonstrating the `duplicate_*()` functions,
such as
[`duplicate_count()`](https://lhdjung.github.io/scrutiny/reference/duplicate_count.md).

## Usage

``` r
pigs4
```

## Format

A tibble (data frame) with 5 rows and 3 columns, describing various body
measures of the fictional pigs. The columns are:

- snout:

  Numeric. Snout width.

- tail:

  Numeric. Tail length.

- wings:

  Numeric. Wingspan.
