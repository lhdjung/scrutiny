# Binary means and standard deviations for DEBIT-testing

A fictional dataset with means and standard deviations from a binary
distribution related to flying pigs. For demonstrating
[`debit_map()`](https://lhdjung.github.io/scrutiny/reference/debit_map.md)
and functions built on it.

## Usage

``` r
pigs3
```

## Format

A tibble (data frame) with 7 rows and 3 columns. The columns are:

- x:

  Numeric. Means.

- sd:

  Numeric. Standard deviations.

- n:

  Numeric. Sample sizes.
