# Percentages and sample sizes for GRIM-testing

A fictional dataset with percentages and sample sizes of flying pigs.
For demonstrating
[`grim_map()`](https://lhdjung.github.io/scrutiny/reference/grim_map.md)
and functions built on it, with `x_meaning = "percentage"`.

## Usage

``` r
pigs2
```

## Format

A tibble (data frame) with 6 rows and 2 columns. The columns are:

- x:

  Numeric. Percentages.

- n:

  Numeric. Sample sizes.
