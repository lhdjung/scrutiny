# Deprecated name of `grim_exp_incon()`

**\[deprecated\]**

`grim_probability()` was renamed to
[`grim_exp_incon()`](https://lhdjung.github.io/scrutiny/reference/grim-stats.md)
in scrutiny 1.0.0, which also requires `digits_x` and `data_type`, takes
`items_averaged` instead of `items` and `x_meaning` instead of
`percent`, and has a `rounding` argument.

## Usage

``` r
grim_probability(...)
```

## Arguments

- ...:

  Passed on to
  [`grim_exp_incon()`](https://lhdjung.github.io/scrutiny/reference/grim-stats.md).
